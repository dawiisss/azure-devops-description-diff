Description

Users report that when attempting to authenticate via OAuth 2.0 with PKCE on mobile devices, the connection drops after 30 seconds due to gateway timeout.

Reproduction steps:

  1. Launch client mobile application
  2. Click on Sign in with Google or Microsoft SSO
  3. Wait for authentication redirect via custom URI scheme
  4. Verify error code 504 on console

Expected result: Auth succeeds within 3 seconds without timeout.
