On-Premise Azure DevOps / TFS Domains

By default, this extension runs on dev.azure.com and *.visualstudio.com. To use an internal Azure DevOps Server or TFS site, enter its address and approve access to that site. Addresses without a scheme use HTTPS. Use an explicit http:// address for an HTTP server. Site access covers that hostname on all ports; URL paths are ignored.
